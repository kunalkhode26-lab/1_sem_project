## 🍽️ Restaurant Website

## 📌 About the Project

The **Restaurant Website** is my first web development project, created using HTML and CSS. The website is designed to present a restaurant in an attractive and user-friendly way, showcasing its food, restaurant atmosphere, and overall online presence.

This project helped me understand the fundamentals of front-end web development and practice creating structured web pages with CSS styling.

## ✨ Features

- 🍴 Attractive restaurant-themed design
- 🎨 Styled layouts using CSS
- 🖼️ Food and restaurant image presentation
- 📱 User-friendly page layout
- 💻 Structured and organized HTML
- 🌐 Restaurant website interface

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layout, colors, and visual design

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/kunalkhode26-lab/restaurant-website.git
```

### 2. Open the Project Folder

```bash
cd restaurant-website
```

### 3. Run the Website

Open the `index.html` file in your web browser.

No additional software or dependencies are required.
